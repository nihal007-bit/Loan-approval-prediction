#  Loan Approval Prediction

An end-to-end Machine Learning application that predicts the credit risk of loan applicants using demographic and financial information. The project leverages the XGBoost algorithm for classification and provides an interactive web interface built with Streamlit for real-time predictions.

---

##  Project Overview

Financial institutions assess an applicant's credit risk before approving a loan. This project automates that process by analyzing applicant information and classifying them as **Good Risk** or **Bad Risk** using a trained XGBoost model.

The application allows users to enter applicant details through an intuitive Streamlit interface and instantly receive a prediction along with confidence scores.

---

##  Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature selection and categorical encoding
- Multiple machine learning model comparison
- Hyperparameter tuning using GridSearchCV
- XGBoost classifier for prediction
- Model evaluation using multiple performance metrics
- Feature importance analysis
- Interactive Streamlit web application
- Real-time prediction with confidence scores
